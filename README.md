#  ViewTrack_ExpenseTracker (  https://trackview.virtualdev.online  )

A full-stack Expense Tracker application that helps users manage their income and expenses with secure authentication, real-time expense tracking, and insightful financial summaries.

---

### Deployed - AWS EC2  PM2 - NGINX  SSL CERTBOT

##  Tech Stack

### Frontend
- React.js
- Redux
- HTML5
- CSS3
- JavaScript (ES6+)

### Backend
- Node.js
- Express.js

### Database
- MySQL
- Sequelize ORM
- AWS RDS


### Authentication & Authorization
- JWT (JSON Web Token)
- Secure Login & Registration
- Protected Routes
- Password Hashing (bcrypt)

### Email Services
- Nodemailer (OTP, Password Reset & Email Notifications)

### Security & Performance
- xss-clean (XSS Protection)
- express-rate-limit (Rate Limiting)
- hpp (HTTP Parameter Pollution Protection)
- compression (Response Compression)
- Helmet (HTTP Security Headers)
- CORS
- Environment Variables (.env)

---

##  Features

-  User Authentication & Authorization
-  Dashboard with Expense Overview
- Add, Edit & Delete Income
- Add, Edit & Delete Expenses
- Financial Summary & Analytics
- Filter Transactions
-  Search Transactions
-  JWT Protected APIs
-  Email Verification & Password Reset
-  Responsive UI
